Streaming services

Netflix, Disney+, Hulu, Prime Video, Max, Paramount+, Peacock, Apple TV+ and the rest have no public watch-history API, so there's no account to connect. BackTrackarr gets those plays four ways. Use any or all of them; duplicates are dropped.

{{if not .CanResolve}}

Set TMDB_API_KEY (free at themoviedb.org) or TRAKT_CLIENT_ID so streaming titles are matched to IMDb/TMDb/TVDB ids. Without one, plays are still stored by title, but can't be sent to Trakt or Simkl.

{{end}}

1. Import a history export

{{range .Users}}

  • Netflix: Account → Profile → Viewing activity → Download all (NetflixViewingHistory.csv), or the fuller ViewingActivity.csv from Account → Download your personal information (it covers all profiles; trailers and previews are skipped).
  • Prime Video: amazon.com → Request My Data → Prime Video; import the viewing-history CSV.
  • Disney+, Hulu, Max, Paramount+, Peacock, Apple TV+…: use each service's privacy/data request, or any tool that exports your history to CSV/JSON. Columns are matched by name (Title, Show/Series, Season, Episode, Date/Watched, Profile…).
  • Files dropped in {{.Cfg.StreamImportDir}} import automatically; put them in a subfolder named after the service (e.g. netflix/, hulu/) to tag them.

2. Track live in your browser

Install a userscript manager (Tampermonkey or Violentmonkey), then:

Install the scrobbler {{if .Users}}or for a user: {{range .Users}}{{.Name}} {{end}}{{end}}

Works on Netflix, Disney+, Hulu, Prime Video, Max, Paramount+, Peacock, Apple TV+, Crunchyroll, Tubi, Pluto TV and more. It reports start, pause and stop, and marks a play watched at 90%. Streaming sites change often, so it's best effort: it reads the player's title, then the browser's media info, then the page title. It contains your webhook token, so install it only in your own browser.

Anything else can send plays too (phone shortcuts, scripts, other tools): POST {{.ScrobbleURL}} with JSON like {"action":"watched","service":"Hulu","raw_title":"Shōgun","subtitle":"S1 E3 · Tomorrow Is Tomorrow"}.

4. Pull from Trakt and Simkl

If you already use Trakt's or Simkl's apps, browser extensions (like Universal Trakt Scrobbler) or their Netflix imports, BackTrackarr pulls those plays in every {{.Cfg.TrackerPull}}. Pulled plays are stored, not sent back out.
